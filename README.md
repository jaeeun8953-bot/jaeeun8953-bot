# 박재은 | 개인정보보호 · 서비스 구현

동의서의 고지·동의 요건을 검토 기준으로 구체화하고, 검출 방식을 직접 구현해 오탐과 미탐이 발생하는 조건을 분석했습니다. Gemini API와 Streamlit을 활용한 웹 서비스도 기획·구현·배포했습니다.

## 개인정보 이용동의서 위험조항 자동 검출

**2023 융합보안 창의·소프트웨어경진대회 우수상**

- 개인정보 수집·이용과 제3자 제공 시 필수 고지 항목, 아동의 법정대리인 동의, 별도 동의 요건을 문장별 검토 기준으로 정리했습니다.
- 안전 문장 1,000개와 위험 문장 1,000개를 구축하고,블랙리스트와 화이트리스트로 나누어 TF-IDF 와 코사인 유사도 기반 검출을 수행했습니다.
-  GPT-3 API 기반으로 기존 유사도 기반 방시과 정확도와 속도면에서 어떠한 차이를 보이는지 검증 코드를 구현하고 판단했습니다.
- 정확도 면에서 유의미한 차이가 나타나지 않아 기존 목록에 없던 변형된 문장을 100개씩 두 차례 추가로 검증했습니다.

| 평가 항목 | 유사도 기반 | GPT API 기반 |
| --- | ---: | ---: |
| 초기 정확도 | 68.78% | 76.05% |
| 신규 유형 200문장 추가 후 정확도 | 59.70% | 72.65% |
| 문장당 평균 처리 시간 | 0.02초 | 59초 |

그 결과, GPT-3를 이용한 방식이 초기 정확도와 더 유사하게 높은 정확도를 보였고 기존 유사도 기반 방식은 새로롭게 투입된 문장에 대한 안정성을 기대하기 어렵다는 결론을 도출했습니다. 따라서 블랙리스트와 화이트리스트를 높은 임계값에 따라 유사도기반 방식으로 검토 대상을 먼저 선별한 뒤 GPT로 정밀 검토하는 방식을 개인정보이용동의서 위험조항 검출 안으로 제안했습니다. 추후 GPT 모델의 발전 전망에 따라 더 GPT API만으로 더 높은 정확도와 검출 속도를 기대하는 전망도 예측했습니다.

### 후속연구 | TF-IDF·코사인 유사도와 GPT-5 비교 검증

기존 연구에서 제안한 후속 검증을 위해 개인정보 수집, 마케팅 동의, 제3자 제공 등 10개 유형의 가상 문장 200개(안전 100개·위험 100개)를 새로 구성했습니다. ‘회신이 없으면 동의한 것으로 간주합니다’와 ‘회신이 없으면 동의한 것으로 간주하지 않습니다’처럼 표현은 비슷하지만 의미가 다른 문장을 짝지어, 두 방식의 판단이 어디에서 갈리는지 확인할 수 있도록 설계했습니다.

Streamlit 검증 앱에서 동일한 문장 20개를 처리할 때마다 두 방식의 정확도와 문장당 평균 처리 시간을 그래프로 표시하고, 유형별 오탐·미탐과 판단이 갈린 문장을 확인할 수 있도록 구현했습니다.

가상 문장 200개에서 유사도 방식은 임계값 20·40·60·80% 기준 평균 정확도 **21.75%**, 문장당 평균 처리 시간 **약 0.00030초**를 기록했습니다. GPT-5의 정확도와 응답 시간은 앱에서 검증을 실행하면 확인할 수 있습니다.
