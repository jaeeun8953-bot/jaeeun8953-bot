# 박재은 | 개인정보보호 · 서비스 구현

동의서의 고지·동의 요건을 검토 기준으로 구체화하고, 검출 방식을 직접 구현해 오탐과 미탐이 발생하는 조건을 분석했습니다. Gemini API와 Streamlit을 활용한 웹 서비스도 기획·구현·배포했습니다.

## 개인정보 이용동의서 위험조항 자동 검출

**2023 융합보안 창의·소프트웨어경진대회 우수상**

- 개인정보 수집·이용과 제3자 제공 시 필수 고지 항목, 아동의 법정대리인 동의, 민감정보·고유식별정보의 별도 동의 요건을 문장별 검토 기준으로 정리했습니다.
- 안전 문장 1,000개와 위험 문장 1,000개를 직접 구축하고, 화이트리스트·블랙리스트를 활용한 TF-IDF·코사인 유사도 기반 검출 방식을 구현했습니다.
- GPT-3 API 기반 판단 방식을 별도로 구현해 동일한 2,000문장에서 두 방식의 정확도와 처리 시간을 비교했습니다.
- 초기 결과만으로 신규 유형에 대한 성능을 판단하기 어렵다고 보아, 기존 목록에 없던 문장을 100개씩 두 차례 추가해 총 200문장을 검증했습니다.

| 평가 항목 | 유사도 기반 | GPT-3 API 기반 |
| --- | ---: | ---: |
| 초기 정확도 | 68.78% | 76.05% |
| 신규 유형 200문장 추가 후 정확도 | 59.70% | 72.65% |
| 문장당 평균 처리 시간 | 0.02초 | 59초 |

GPT-3 기반 방식은 유사도 기반 방식보다 정확도가 높았으며, 신규 유형 추가에 따른 정확도 하락 폭도 작아 더 안정적인 결과를 보였습니다. 처리 속도는 유사도 기반 방식이 더 빨랐습니다. 임계값에 따른 오탐·미탐의 변화를 분석하고, 유사도로 검토 대상을 먼저 선별한 뒤 GPT로 정밀 검토하는 방식을 개선안으로 제안했습니다. 향후 GPT 모델의 발전에 따라 정확도와 처리 속도가 개선될 가능성도 전망했습니다.

### 후속연구 | 동일한 2,000문장에서 GPT-5 재평가

기존 실험에 사용한 안전 1,000문장·위험 1,000문장과 당시 정답 라벨을 복원했습니다. Streamlit 검증 앱에서 정답을 제외한 문장을 GPT-5에 200개씩 총 10회 요청하고, 반환된 판정을 기존 정답과 대조했습니다. 유사도 기반·GPT-3의 기존 결과와 GPT-5의 새 실측 결과를 비교했습니다.

| 평가 항목 | 유사도 기반 | GPT-3 | GPT-5 |
| --- | ---: | ---: | ---: |
| 정확도 | 68.78% | 76.05% | **98.80%** |
| 문장당 평균 처리 시간 | 0.02초 | 59초 | **0.408초** |
| 결과 구분 | 기존 실험 | 기존 실험 | 이번 실측 |

![동일한 2,000문장에서 세 방식의 분류 정확도 비교](assets/accuracy-comparison.png)

![세 방식의 처리 시간 비교](assets/speed-comparison.png)

GPT-5는 2,000문장 중 1,976문장을 정분류해 정확도 98.80%를 기록했으며, 기존 GPT-3의 76.05%보다 22.75%p 높았습니다. 누적 정확도는 전 구간에서 98% 이상을 유지했습니다. 이번 실험에서 GPT-5의 문장당 환산 처리 시간은 0.408초로, 기존 GPT-3 실험의 59초보다 짧게 측정되었습니다.

GPT-5의 0.408초는 200문장씩 묶어 요청한 총 처리 시간을 2,000문장으로 나눈 값입니다. 한 문장을 단독 요청했을 때의 응답 시간과는 구분됩니다.
